# BN Chart (TradingView 引擎版)

基于 TradingView 官方 Lightweight Charts 引擎构建的高性能加密货币行情与交易终端 Web 应用。

## 🌟 核心特性
- **TradingView 4.2+ 引擎驱动**：毫秒级 K 线渲染与平滑交互，支持高并发 WebSocket 行情推送。
- **iPad / 平板触控专属适配**：拦截浏览器默认视口缩放与手势冲突，多指捏合缩放聚焦图表本身。
- **极简高效交互**：
  - 点击左上角币种名称一键切换 5m / 1h 周期；
  - 屏幕左右 20% 边缘轻击快速翻页轮巡观察列表币种；
  - 左下角 TV 水印聚合按钮，一键调出持仓与机会看板。
- **智能开仓与盈亏比浮动气泡**：长按图表选点，动态计算止损距离百分比、实时盈亏比 (R:R) 与可用保证金。
- **极致护眼模式**：低饱和暖羊皮纸与夜间暗灰配色，专为长时间盯盘设计。
- **纯前端零依赖**：单文件绿色架构，支持纯静态部署（GitHub Pages）。
